## How to install BetterSFS
### ❗ BetterSFS uses [UI Tools](https://github.com/cucumber-sp/UITools) mod as dependency and won’t work without it!
1. Go to [releases](https://github.com/TheMaxPanch/BetterSFS/releases).
2. Download latest `BetterSFS.zip`.
3. Unpack it.
4. Launch **Spaceflight Simulator**.
5. Click **Mod Loader** in main menu.
6. Click **Open Mods Folder**.
7. Move the unpacked folder `BetterSFS` to `Mods` folder.
8. Restart **Spaceflight Simulator**.
